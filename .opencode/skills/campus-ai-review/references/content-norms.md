# 校园拾光 · 内容规范（AI 预审知识库）

> 这是 AI 预审 Agent 的唯一判级依据。人工审核台（moderation.html）的六条驳回理由是本规范的下游——AI 的理由措辞应能与这六条对上，站主复核时才顺畅。
> 适用范围：帖子的**文字部分**。AI 看不到图片内容，带图帖一律在理由末尾注明「图片请人工确认」。

## 1. 判级标准（三档）

### reject —— 建议驳回（内容明确违规）

命中任一条即 reject，理由里写明对应哪条：

| # | 情形 | 对应人工驳回理由 |
|---|---|---|
| R1 | 违法违规：毒品、赌博、枪械、诈骗、 exam 代考代写、翻墙/VPN 售卖等 | 其他原因，我写在下面 |
| R2 | 脏话、辱骂、人身攻击、地域/性别/群体歧视、威胁恐吓 | 有脏话或者人身攻击 |
| R3 | 广告、引流、拉人进群、代购刷单、招聘收费、二维码/微信号/群号引流 | 像广告、引流或拉人进群 |
| R4 | 隐私泄露：手机号、住址、身份证号、学号+姓名组合、真实姓名指名道姓攻击、他人照片身份信息 | 涉及隐私（手机号、住址、真实姓名） |
| R5 | 色情低俗、软色情擦边描写 | 其他原因，我写在下面 |
| R6 | 内容与平台无关且明显扰乱（如无意义刷屏字符、机器乱码、纯测试灌水——「看不出在说什么」） | 看不出在说什么，像是随手打的 |

### flag —— 存疑（拿不准，请人工把关）

- 疑似 R3 引流但语气像真实求助（如「求拼车，加我 wx」——可能真拼车也可能引流）；
- 情绪极端（自伤倾向、绝望表述）：**flag 而非 reject**，理由里建议站主优先处理、温和回应；
- 涉及金钱往来、二手交易但未违规；
- 转发外部链接但内容未知；
- 文字过短且语境不足难以判断。

### pass —— 放行建议（正常分享）

日常记录、校园生活、求助提问、吐槽（无攻击对象）、心情表达、照片分享的文字说明等。**pass 不代表最终通过**，只是「文字无碍」的建议。

## 2. 理由写作要求

1. 中文，一句话到两句话，最长 200 字（数据库会截断）。
2. 说清命中了规范的哪一条（如「命中 R3：正文含群号邀请语」）。
3. 对事不对人：描述内容问题，不定性作者本人，不写侮辱性措辞。
4. 带图帖子（`has_image = true`）：理由末尾必须写「图片请人工确认」。
5. 匿名帖（`is_anonymous = true`）与署名帖同一标准，不因匿名加严或放宽。
6. R6（看不出在说什么）要给出具体观察（如「正文为重复字符」），避免误伤真实的情绪化表达。

## 3. 判级倾向

- 拿不准就 flag，不硬判 reject（误驳回的伤害大于漏放行）。
- 情绪类内容宁可 flag 交人工：审核员还能顺手送一句抱抱。
- 不要因为内容无聊、质量低而 reject——平台接纳「没有压力的分享」，只有违规才驳回。

## 4. 输出格式（第 3 步产物）

```json
[
  {"id": "uuid", "verdict": "pass", "reason": "日常校园记录，未命中 R1-R6。图片请人工确认。"},
  {"id": "uuid", "verdict": "flag", "reason": "命中 flag：疑似引流（正文含微信号），但也可能是真实拼车求助，请人工把关。图片请人工确认。"},
  {"id": "uuid", "verdict": "reject", "reason": "命中 R2：正文含辱骂性词汇，针对具体个人。"}
]
```

- `id` 必须与 fetch 返回的帖子 id 一致，一条不落（包括判 pass 的也要写，便于全量留痕）。
- `verdict` 只能是 `pass` / `flag` / `reject`。
- `reason` ≤ 200 字；为空会被数据库接受，但规范上不允许——每条都要有理由。
