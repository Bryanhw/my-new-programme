## 1. 阶段目标

做出一版**可以初步使用**的校园生活分享网站，核心要求：

- 同学能分享日常（文字 / 图片）；
- **两种说话方式都可用**：匿名发表，和注册账号后署名发表（发布与评论/回复都走这两条路径）；
- 有一个能看到其他用户发言的「广场」；
- 站点所有者能在后台**审核评论、应对举报**；
- 电脑端与手机端都能正常使用。

一句话：**先能跑起来、能用起来——不追求功能多，追求「两条身份路径 + 一个内容广场 + 一条站主治理链」全部打通。**

## 2. 这个阶段做什么 / 不做什么

本阶段做：主页、登录/注册验证页、发布能力、内容广场、评论与回复（匿名/账号两种身份）、先发后审、站主审核与举报处理、上线部署与端到端验收。

本阶段不做（推到后续阶段，见 PROJECT_SCOPE.md 第 5 节）：

- 图片展示优化（看原图入口、竖图不裁人、`srcset`）；
- 话题标签筛选、置顶、卡片「⋯」完整操作区、轻反应；
- 私信 / 关注等社交扩展；原生 App。
