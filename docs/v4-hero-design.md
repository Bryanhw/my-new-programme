## 2. 决策点（需站主逐一确认后落码）

### D1 · 校门图 `hero-gate`（school-gate.png）去留
- A（推荐）：**保留**，缩小置于操场中央作视觉锚点，白晕贴纸化延续；
- B：**移除**，场景纯粹靠窗/操场/远山，无具体实物。

### D2 · 窗的开合角度 / 入场动效
- A（推荐）：**半开**（`rotateY(±22deg)` + 内缘玻璃高光），进入时一次开窗入场动画后静止；
- B：**全开**（`rotateY(±45deg)` 更明显透视）；
- C：**平开不动**（无入场动画，仅静态窗框）。

### D3 · 操场透视细节
- A（推荐）：**椭圆草地 + 单圈跑道环**（低饱和，`--sky-*` 同系）；
- B：**完整跑道（双弧 + 直道 + 内沿）**，细节更高但可能抢焦点；
- C：极简——只一条地平线草地（最弱化）。

### D4 · 远山层数与色调
- A（推荐）：**2 层**青灰蓝阶梯山影（最远层可挂极缓视差漂移）；
- B：3 层含雾感；
- C：1 层最干净。

### D5 · 云量（接续现有）
- A（推荐）：**3 套**（远 130s / 中 86s / 新最远更淡 180s）；
- B：2 套（沿用现成，不新增）；
- C：1 套最安静。

### D6 · 移动端（390px）窗的处理
- A（推荐）：窗**弱化为下缘装饰条**或隐藏，防挡标题（沿现有小屏规则）；
- B：窗保留但收窄；
- C：与桌面一致（不推荐，易挤标题）。

## 3. 实现承诺（无论 D1–D6 选什么）

- 纯 CSS / SVG 分层，零新大图（素材 ≤120KB、可 WebP）；不引 JS 动画库。
- 动画只动 `transform` / `background-position-x` / `opacity`；
  `prefers-reduced-motion: reduce` 下所有动态静止，场景完整可读。

- 内容层（问候/标题/pills/CTA）始终在场景之上，对比度不降级。
- 回归：静态 1091→（+N）、运行 932→（+M）、`campus_compare` 304 不变；逐字节发版。
